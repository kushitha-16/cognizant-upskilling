# Module 3 - JDBC Exercises

This folder contains JDBC practice programs.

## Files

- BasicJDBCConnection.java
- JDBCInsertDemo.java
- JDBCSelectDemo.java

## Concepts Practiced

- JDBC connection
- DriverManager
- Connection
- PreparedStatement
- Statement
- ResultSet
- Insert query
- Select query

## Note

These programs require MySQL and MySQL Connector/J to run successfully.
If MySQL is not configured, the program may show a connection error.
